# Projeto

## Stack
- (Next / Vite / etc.) + TypeScript
- Tailwind + shadcn/ui (Base UI)

## Comandos
- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build
- `npm run lint`: lint

## Regras
- Componentes em `components/ui` devem ter estilização mínima: só estrutura e acessibilidade, sem cores, sombras ou bordas decorativas.
- Não reintroduzir o visual padrão do shadcn ao adicionar componentes novos.
